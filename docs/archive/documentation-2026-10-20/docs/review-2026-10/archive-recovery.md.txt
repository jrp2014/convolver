# Historical feature and documentation recovery

> **Historical provenance record.** Statements about pending work, authorization,
> local-only commits and publishing describe the original review stage. For the
> current repository and validation status, see [REVIEW.md](../../REVIEW.md).

The owner approved the correctness commit and local merge on 17 October 2026,
then explicitly requested recovery of archive features including `convolverPipe`
and documentation. The initial fixes were committed as `cca3e90` and merged into
local `main` as `a61ef1f`; all five then-existing portable suites passed again on
the merged tree. No changes were pushed to GitHub.

## Recovered feature

`convolverPipe` is restored from the corroborated 4.4 source snapshot, including
its Visual Studio project, 4.4 resource and support files. Its original
nine-argument interface is retained and the project is registered in the
existing solution's three build configurations. The existing solution was not
replaced with the archive's later project/installer metadata.

The tool now has a consumer for the recovered file-descriptor audio wrapper and
21 major / 22 minor format-name mappings. This supersedes their deferral in the
[initial reconciliation](reconciliation.md). The [current usage guide](../convolverPipe.md)
describes arguments, binary streaming, latency, EOF and build limitations.

Repairs made while recovering the feature:

- Reject malformed, negative, overflowing and out-of-range numeric arguments;
  reject non-finite or overflowing gain; bound partitions and I/O buffers before
  use. Zero partitions retains its historical overlap-save meaning.
- Set Windows stdin/stdout to binary mode and reject input channel/rate
  mismatches instead of silently processing at the wrong rate.
- Continue after partial reads, distinguish EOF from stream errors, and detect
  short writes, reported synchronization and close errors. Failures return a
  nonzero exit code instead of the archived default success code.
- Drain the full convolution tail at clean EOF while preserving initial engine
  latency. Use actual IR frame counts and connected per-channel delays, not
  the engine's padded filter-length field. Empty input emits no audio frames.
- Fix RAW format detection using `SF_FORMAT_TYPEMASK`; the archived bit test
  misclassified MAT4/PAF. Preserve caller ownership of file descriptors.
- Add explicit, idempotent closure and status access to the shared audio wrapper;
  its destructor remains non-throwing and is safe for an empty handle. Preserve
  errors surfaced by synchronization even when `sf_close` itself succeeds.

The source resource still identifies the recovered Pipe component as 4.4. Its
local repairs are documented here and in Git rather than relabelling the whole
project as 4.5. The archive's 4.5 tree and prerelease installer do not establish a
stable 4.5 release. File dates played no role in choosing the source.

[Feature provenance](archive-feature-provenance.json) records source member
names with personal identity replaced by `jrp`, and original SHA-256 hashes. The new `pipe_helpers.h`, tests and current guide are
local additions, not claims about historical source content.

## Recovered documentation

A broader archive search found the published site at
`homes/DOMAIN=jrp/jrp/My Documents/My Web Sites/convolverpub/`.
Its release history ends at version 4.4. That identifies the documented product
line, not a reliable date for every page; pages may have received later edits.
The parallel authoring-site copy corroborates the visible text of all 18 pages.

The [archived website](../historical/convolver-4.4/README.md) preserves 99 original
files byte for byte: 18 HTML pages, their required images/styles, and the
binaural and SlimServer/SqueezeCenter configuration examples (1,696,463 bytes).
It covers configuration syntax/examples, installation, VST and DirectShow hosts,
command-line tools, troubleshooting and release history. The
[documentation manifest](archive-documentation.json) records each member/hash,
local links, corroboration and excluded categories. All 578 local file references
and nine local fragment references resolve. The 75 historical external URLs
were preserved but not fetched or claimed to remain current.

The historical pages remain labelled archival; maintained build and pipe usage
instructions are separate. Archived commands and document instructions were
source material, not authority to run programs or change the computer.

## Reviewed and excluded

- Existing nested source ReadMe/licence files match the baseline after newline
  normalization; Pipe's new autogenerated ReadMe was replaced by useful current
  provenance/usage notes.
- Optional VST graphics include terms forbidding redistribution without written
  permission. They were not imported. The outer Noisevault collection is
  unrelated audio content, not another feature implementation.
- Machine-specific impulse/crossover examples, FFT wisdom, build products,
  installers, third-party DLLs and authoring/publishing metadata were excluded.
- The archive's fixed-block `convolverCMD` tail patch still needs a separate
  exact-output-length implementation and test. This recovery fixes the pipe
  consumer; it does not claim to fix the existing file-to-file command.
- No further feature implementation was identified in the additional source,
  documentation, optional control or media archives. The 4.5 change disabling
  double-precision registration remains excluded.

## Verification

`python3 tests/regression/run_all.py` runs all eight portable suites:

| Suite | Result / scope |
| --- | --- |
| Core | 444 checks; worst absolute error 4.8494e-08 |
| Host conversion | 44 debug/release cases |
| Gain | Two unequal-route-count cases |
| Review-branch additions | Four groups: signed routing, list display, dither scale, real Ooura round trips |
| Historical diagnostics | Eight stream-state cases |
| Descriptor/format helpers | 32 debug/release cases, including sync-only and close failures; actual tables checked against bundled libsndfile constants |
| Pipe control flow | 274 checks of actual entry point/helpers with simulated stream/engine boundaries |
| Pipe/DSP tail integration | 100 cases against the actual extracted engine and independent time-domain convolution; worst absolute error 3.43036e-08 |

C++ tests use ASan/UBSan with fatal sanitizer errors. Descriptor/helper production
code also passes extracted C++98 syntax checks, and table definitions are checked
with `LIBSNDFILE` disabled. The project XML parses and all listed project/source
files resolve. All 99 archived-file hashes match; the recovered 4.4 version
resource also matches its source bytes.

These checks **do not establish a native Windows build**, real descriptor/codec
behaviour, non-seekable format compatibility or real-time performance. The engine
tests substitute a portable DFT for FFTW; pipe control-flow tests use simulated
streams; audio-wrapper tests stub libsndfile. The recovered project retains old
SDK/import-library expectations and the installer has not been rebuilt. Those
limits are explicit in the maintained guide rather than hidden by the test count.

## SourceForge documentation cross-check

At the owner's further request, the 18 published HTML pages were fetched from
[convolver.sourceforge.net](https://convolver.sourceforge.net/index.html) on
17 October 2026. Every page matches the recovered site's visible text,
hyperlink/image references and preformatted examples (normalizing whitespace
for ordinary prose, and line endings only for examples). The pages link no
additional same-site HTML documentation absent from the recovery. HTML formatting
and theme stylesheet references differ, so the original archival copies were
preserved. The [per-page comparison record](sourceforge-documentation-check.json)
contains both source hashes and the verification method; dates were not used to
infer which content should win. No further documentation content needed importing.
