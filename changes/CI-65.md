# CI-65

## For contributors

- Tests (CI-65): the CMake package consumer cases now say what they prove.
  A case that asks for a missing component (`packaging.consumer.missing-host`,
  `missing-io`, `missing-component`) ends once configuration has refused it
  and checked its message, and fails if the consumer project did not report
  the refusal; it no longer builds an empty project and runs CTest on zero
  tests. Every consumer that is built runs CTest with `--no-tests=error`, so
  losing `consumer.convolution` turns the case red instead of passing with
  nothing run ([package tests](../docs/develop/library.md#what-verifies-the-package)).
