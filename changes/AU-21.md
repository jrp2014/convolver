# AU-21

## Fixed

- Audio Unit (AU-21): choosing a filter file in the window now tells the
  host that the plug-in's state and present preset have changed on the
  host's main thread, as the plug-in's other notifications already are. A
  host that passed the choice on from another thread could otherwise have
  had its listener list read while it was changing it.

## For contributors

- `Effect::load_file` sends `kAudioUnitProperty_ClassInfo` and
  `kAudioUnitProperty_PresentPreset` through `tell_listeners()` with two
  new notice bits, instead of calling `PropertyChanged` on the calling
  thread. `au.adapter` `chosen_file_notices` chooses a file from another
  thread and requires both notifications, on the main thread only, then on
  the main thread at once
  ([plug-in contract](../docs/develop/plugin-contract.md#status-and-log)).
  Compiled and run only by the macOS CI jobs.
