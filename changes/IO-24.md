# IO-24

## Changed

- Command line (IO-24): without `--output-format`, the output's extension
  picks the file type: `.flac` writes 24-bit FLAC, `.aif`, `.aiff` and
  `.aifc` 24-bit AIFF, and `.rf64`, `.w64`, `.caf`, `.raw` and `.pcm` 32-bit
  float in that container. `.wav` and names without a known extension are
  still 32-bit float WAV. `out.flac` was a WAV file before. A build without
  FLAC refuses an output named `.flac` before any file is created
  ([output formats](../docs/use/command-line.md#output-formats)).

## For contributors

- Tests (IO-24): `native.cli` renders each extension without
  `--output-format`, checks that the file matches the same render with the
  format named, that 24-bit output accepts dither, and that a build without
  FLAC refuses `.flac`. The warning test now gives `--output-format`.

## Decisions: Identities and file formats

- **28 November 2026.** The command line's output type follows the output's
  extension when `--output-format` is not given ("Yes", to "should a `.flac`
  extension pick the format?"). FLAC and AIFF get 24-bit PCM, as neither
  has a plain float type; the rest get 32-bit float. `--output-format` still
  wins, with a warning when it disagrees with the name. See
  [output formats](../docs/use/command-line.md#output-formats).
