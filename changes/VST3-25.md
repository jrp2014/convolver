# VST3-25

## For contributors

- Tests (VST3-25, from jrp's review of the shared-processor proposal, 24
  November 2026): `vst3.sync` generates sequences of host calls, window
  choices and message deliveries for one processor and controller pair,
  every sequence of one and two steps in every connection, delivery and
  restore-order variant plus seeded random longer ones, and judges each by
  one oracle: once the host has delivered everything, the controller, the
  host's view, the window's settings line, what plays, the latency the host
  last read, the save and a processor reopened from it all match the latest
  step that succeeded. Named cases cover two instances, closing one, a
  processor with no controller, an offline restore on another thread and a
  save before a Gain edit is delivered. On `main` at `3e3d5ef` 241 of 3,684
  sequences failed, all with a window preset or a restore whose messages a
  proxy delivered later (the cases pull request #281 addresses). See
  [VST3 tests](../docs/develop/testing.md#vst3-tests).
