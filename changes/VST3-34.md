# VST3-34

## Fixed

- VST3 (VST3-34): a host that passed a parameter value that is not a number
  (NaN) could crash the plug-in: the Latency and Gain mode conversions
  turned it into an index far past their lists, for example when the host
  asked for Latency's text. Such a value now counts as the parameter's
  default wherever it is converted, as it already did on the Audio Unit,
  and the controller refuses to store one. No change for any other value
  ([plug-in contract](../docs/develop/plugin-contract.md#settings)).

## For contributors

- Tests (VST3-34): `vst3.adapter` passes NaN to the conversions,
  `getParamStringByValue` and `setParamNormalized` for every setting; before
  the fix the sanitizer build stopped at an out-of-bounds read of
  `host_latencies`. From Claude's audit of 0.22.0.
