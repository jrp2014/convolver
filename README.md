# Convolver

Convolver applies FIR filters (impulse responses) to multichannel audio. Typical
uses are digital room correction, crossovers and routing or mixing channels, for
example applying filters generated by DRC, REW or Audiolense to music files or a
live stream.

It runs on macOS, Linux and Windows and comes in three forms:

- a **command-line tool** that filters WAV files or raw audio streams
- a **VST3 plug-in** for DAWs and other plug-in hosts
- a **C++20 library** you can build into your own program

Filters are given either as a multichannel impulse-response WAV or as a
Convolver **`.cfg` file**, a simple text format that Roon, JRiver Media Center
and Audiolense also read. Existing `.cfg` files keep working.

## Build

You need CMake 3.20 or later, a C++20 compiler, FFTW (single precision) and
libsndfile.

```sh
# macOS (Homebrew)
brew install cmake fftw libsndfile
# Debian or Ubuntu
sudo apt-get install cmake g++ libfftw3-dev libsndfile1-dev
```

Then, from the repository root:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
ctest --test-dir build --output-on-failure
./build/convolver --version
```

On a Mac you can use Apple's Accelerate framework instead of FFTW by adding
`-DCONVOLVER_FFT_BACKEND=ACCELERATE` to the first command. Windows builds use
vcpkg; see the [portable guide](docs/portable-core.md#windows-build).

## Filter a file

With a multichannel impulse response, each IR channel filters the matching
input channel:

```sh
./build/convolver --filter impulse.wav --input music.wav --output corrected.wav
```

With a configuration file:

```sh
./build/convolver --filter room.cfg --input music.wav --output corrected.wav --output-format wav-pcm24
```

Output is 32-bit float WAV unless you choose `wav-pcm16`, `wav-pcm24`,
`wav-pcm32` or `raw-float`. Use `--gain-db -3` (or any value) to lower the level
and avoid clipping. The output keeps the whole filter tail, and Convolver's
processing delay is removed, so the result lines up with the input. The input
sample rate and channel count must match the filter; Convolver does not resample.

To filter a live stream, pipe raw 32-bit float audio through it:

```sh
producer | ./build/convolver --filter room.cfg --input - --raw-input 48000 2 \
  --output - --output-format raw-float | consumer
```

Run `./build/convolver --help` for every option.

## Configuration files

A `.cfg` file names the sample rate and channel counts, any per-channel delays,
and one or more filter paths. This stereo example applies channel 0 of
`room.wav` to the left channel and channel 1 to the right:

```text
// 48 kHz, 2 inputs, 2 outputs, speaker mask 3 (front left and right)
48000 2 2 3
0 0
0 0
// left: channel 0 of room.wav, input 0 to output 0
room.wav
0
0
0
// right: channel 1 of room.wav, input 1 to output 1
room.wav
1
1
1
```

The second and third lines are input and output delays in milliseconds. Each
path is four lines: the IR file, which channel of it to use, the input channels
it reads and the output channels it writes to. A fractional part on a channel
number is a gain, so `0.5` means channel 0 at half level, and `-0` means channel
0 inverted. File names are relative to the `.cfg` file itself. A text file that
lists several `.cfg` files lets Convolver pick the one matching the input's
sample rate and channel count.

Check a configuration before using it:

```sh
./build/convolver --validate room.cfg
./build/convolver --inspect room.cfg
```

`--inspect` shows each path, its routing, latency and filter length; add
`--json` for machine-readable output. The full syntax is in the
[configuration reference](docs/historical/convolver-4.4/config.html), with
[examples](docs/historical/convolver-4.4/configegs.html).
[Configuration compatibility](docs/configuration-compatibility.md) covers moving
`.cfg` files between platforms and what other programs accept.

## VST3 plug-in

The plug-in is optional and needs the Steinberg VST3 SDK, fetched separately.
Filters are loaded through the host's preset menu: a small tool converts a WAV
or `.cfg` file into a `.vstpreset`. See the [VST3 guide](docs/vst3.md).

## History

Convolver started in 2005 as a set of Windows applications: a Windows Media
Player plug-in, a DirectShow filter, a VST 2 plug-in and command-line tools. Their
documentation is at <https://convolver.sourceforge.net/>. That code is preserved
in [`convolver/`](convolver/) but is not built by this project. The
[history page](docs/history.md) explains where it came from and how the
portable implementation replaced it.
