# Synthetic plug-in examples

Generated by [generate_examples.py](../../scripts/release/generate_examples.py),
authored by jrp, licensed GPL-2.0-or-later. No recorded or third-party audio is used.

The build produces 18 labelled examples: mono and stereo, at 44100, 48000 and
96000 Hz, each with identity, a two-tap echo and a two-tap repeat. WAV
coefficients are IEEE float32. Identity is exactly 1 at sample 0; echo is 0.5
at sample 0 and 0.25 at sample 257 (about 5 ms, heard as a hollow tone, not a
repeat); repeat is 0.5 at sample 0 and 0.25 a quarter of a second later (sample
11025, 12000 or 24000), heard as a distinct repeat.
Stereo applies the same response independently to each channel; no crossfeed.

Expected output is the convolution of input with those taps, delayed by the
plug-in's reported 256 samples. `examples.json` records the exact coefficients.
Each directory contains `impulse.wav`, a relative-path `filter.cfg`, and an
embedded `filter.vstpreset`. WAV and configuration imports produce identical
presets. Presets retain the filters after the WAV and config are removed.
